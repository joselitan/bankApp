Getting Started

Getting Started

Install dependencies, configure the environment, and make your first API call in under five minutes.

Prerequisites

  • Python 3.11 or higher
  • pip (bundled with Python 3.11+)
  • Git (to clone the repository)
  • A terminal (bash, zsh, PowerShell)
  • Optionally: Postman or curl for manual API testing

Installation

Clone the repository

Get the source code onto your machine.

git clone https://github.com/joselitan/bankApp.git
cd bankApp

Create a virtual environment

Isolate project dependencies from your system Python.

python -m venv .venv
source .venv/bin/activate      # macOS / Linux
# .venv\Scripts\activate       # Windows PowerShell

Install dependencies

Install the package in editable mode with all development extras.

python -m pip install -U pip
python -m pip install -e '.[dev]'

Configure environment (optional)

Create a .env file to override default settings. All settings have sensible defaults for local development.

# .env (optional — copy this template)
DATABASE_URL=sqlite:///./securecore_bank.db
SECRET_KEY=your-super-secret-key-change-in-production
⚠️
The default SECRET_KEY is dev-only-change-me. Always override this in any non-local environment.

Environment Variables

VariableDefaultDescription
DATABASE_URL sqlite:///./securecore_bank.db SQLAlchemy database URL. Change to postgresql://... for Postgres.
SECRET_KEY dev-only-change-me Secret used to sign and verify JWT tokens. Must be a long, random string in production.
APP_NAME SecureCore Bank Display name shown in the OpenAPI documentation.

Running the Server

Start the development server with auto-reload:

# Using uvicorn directly
uvicorn app.main:app --reload

# Or using the Makefile target
make run

The server will start at http://127.0.0.1:8000. The database file securecore_bank.db is created automatically on first startup.

✅
On startup the app calls Base.metadata.create_all() via the lifespan handler, so all tables are created automatically — no migration tool needed for SQLite.

Verify the Server is Running

curl http://127.0.0.1:8000/health

Expected response:

{"status": "ok"}

Interactive API Docs (Swagger UI)

FastAPI automatically generates interactive documentation. Open your browser and visit:

http://127.0.0.1:8000/docs

From the Swagger UI you can explore all endpoints, view schemas, and execute requests directly in the browser without any additional tooling.

Your First API Workflow

Here is a complete end-to-end curl workflow to register, log in, deposit, and transfer.

1. Register a user

curl -s -X POST http://127.0.0.1:8000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email":"alice@example.com","full_name":"Alice Smith","password":"Secure1!"}'

Response (201):

{
  "id": 1,
  "email": "alice@example.com",
  "full_name": "Alice Smith",
  "account_number": "a1b2c3d4e5f6g7h8"
}

2. Log in and get a token

curl -s -X POST http://127.0.0.1:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"alice@example.com","password":"Secure1!"}'

Response (200):

{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer"
}

3. View account balance

curl -s http://127.0.0.1:8000/api/accounts/me \
  -H "Authorization: Bearer <your_token>"

4. Deposit funds

curl -s -X POST http://127.0.0.1:8000/api/transactions/deposit \
  -H "Authorization: Bearer <your_token>" \
  -H "Content-Type: application/json" \
  -d '{"amount": "500.00"}'
