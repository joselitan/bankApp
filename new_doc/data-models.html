Data Models

Entity–Relationship diagram and detailed column reference for all four database tables.

Entity–Relationship Diagram

The database consists of four tables. One user owns one account (MVP assumption), one account holds many transactions, and users generate many audit log entries.

erDiagram USERS { int id PK string email UK string full_name string password_hash int failed_login_attempts datetime locked_until datetime created_at } ACCOUNTS { int id PK int user_id FK string account_number UK string name decimal balance datetime created_at } TRANSACTIONS { int id PK int account_id FK string type decimal amount string description datetime created_at } AUDIT_LOGS { int id PK int user_id FK string action decimal amount string ip_address string details datetime timestamp } USERS ||--o{ ACCOUNTS : "owns" ACCOUNTS ||--o{ TRANSACTIONS : "records" USERS ||--o{ AUDIT_LOGS : "generates"

Table: users

Stores all registered users. Tracks authentication state including failed login attempts and lockout timestamp.

ColumnTypeConstraintsDescription
idINTEGERPK, auto-incrementUnique user identifier
emailVARCHAR(255)UNIQUE, NOT NULL, indexedNormalised to lowercase. Used as the login identifier.
full_nameVARCHAR(255)NOT NULLDisplay name for the user
password_hashVARCHAR(255)NOT NULLPBKDF2-SHA256 hash of the password (via passlib)
failed_login_attemptsINTEGERNOT NULL, default 0Counter incremented on each bad-password attempt. Reset to 0 on successful login.
locked_untilDATETIMEnullableNaive UTC datetime. If set and in the future, login is blocked with HTTP 423.
created_atDATETIME(tz)NOT NULLUTC timestamp of user creation.

Table: accounts

Each user has exactly one Savings account in the MVP. The account is created atomically during user registration.

ColumnTypeConstraintsDescription
idINTEGERPK, auto-incrementUnique account identifier
user_idINTEGERFK → users.id, indexed, NOT NULLOwner of the account. Cascade delete enabled.
account_numberVARCHAR(32)UNIQUE, indexed, NOT NULL16-character random hex string generated with secrets.token_hex(8)
nameVARCHAR(32)NOT NULL, default "Savings"Account label. Always "Savings" in Sprint 1.
balanceNUMERIC(18,2)NOT NULL, default 0.00Current balance. Stored as fixed-precision decimal to avoid floating-point errors.
created_atDATETIME(tz)NOT NULLUTC timestamp of account creation.

Table: transactions

Immutable ledger entries. Each deposit or transfer creates one (deposit) or two (transfer) records.

ColumnTypeConstraintsDescription
idINTEGERPK, auto-incrementUnique transaction identifier
account_idINTEGERFK → accounts.id, indexed, NOT NULLThe account this transaction belongs to. Cascade delete enabled.
typeVARCHAR(32)NOT NULLOne of: deposit, transfer_in, transfer_out
amountNUMERIC(18,2)NOT NULLAlways stored as a positive value. Direction is implied by type.
descriptionVARCHAR(255)nullableHuman-readable note. Transfer records include counterparty email (e.g. to=bob@example.com).
created_atDATETIME(tz)NOT NULL, indexedUTC timestamp. Indexed to support efficient daily-limit queries and history retrieval.

Table: audit_logs

Append-only event log. Every key action (success or failure) writes a row here, including unauthenticated events like failed logins from unknown emails.

ColumnTypeConstraintsDescription
idINTEGERPK, auto-incrementUnique log entry identifier
timestampDATETIME(tz)NOT NULL, indexedUTC time of the event.
user_idINTEGERFK → users.id, indexed, nullableNULL for unauthenticated events (e.g. login attempt with unknown email).
actionVARCHAR(64)NOT NULLEvent type string (see table below).
amountNUMERIC(18,2)nullableMonetary amount for deposit/transfer events. NULL for auth events.
ip_addressVARCHAR(64)nullableClient IP address. Best-effort; may be NULL if not available.
detailsVARCHAR(255)nullableExtra context, e.g. duplicate_email, insufficient_funds, to=bob@example.com.

Audit Action Catalog

ActionTrigger
register_successNew user and account created successfully
register_failureRegistration attempt failed (bad password or duplicate email)
login_failureWrong password or unknown email
login_lockedLogin attempted while account is locked
depositSuccessful deposit operation
transferSuccessful transfer operation
transfer_failureTransfer rejected by a business rule
