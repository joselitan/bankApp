What is SecureCore Bank?

SecureCore Bank is a backend-only banking REST API designed as a training and portfolio project. It demonstrates real-world patterns such as secure authentication, transactional database operations, business-rule enforcement, audit logging, and automated testing — all within a clean, well-structured Python project.

The system is managed through a Jira-driven agile process with GitHub Actions automating both sprint planning and the API regression test suite.

🔐

Secure Authentication

JWT Bearer tokens, PBKDF2-SHA256 password hashing, and automatic account lockout after 3 failed login attempts (10-minute cooldown).

💳

Banking Operations

Deposit funds ($1–$10,000) and transfer money between users (min $0.01, $5,000 daily limit) with full DB transaction atomicity.

📋

Complete Audit Trail

Every key action — registration, login attempts, deposits, transfers — is logged to an audit table with IP address, timestamp, and details.

🧪

Fully Tested

8 pytest test files covering all business rules, boundary conditions, lockout behavior, atomicity, and audit log creation per JIRA ticket.
